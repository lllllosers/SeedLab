# 幼苗测定业务规则（Stage 3 已发布，v0.4.0）

## 计划与任务

每个实验配置任意非负 DAG 节点。幼苗样本的 `germinated_at` 是首次巡检判定发芽的时间；将它转为 `SEEDLAB_TIMEZONE` 指定的实验室日期，再加 DAG 自然日得到计划测定日期。时区默认 Asia/Shanghai。置床时间只用于培养皿和发芽巡检，不参与 DAG。缺少发芽判定时间的历史样本显示“无法安排”，不猜补日期。

任务由样本 × 测定节点动态派生，没有测定行时按计划日期分为已逾期、今日待测或后续任务；有完整测定行即已完成。逾期测定仍可录入。今日完成按实际测定时间的本地日期统计。计划日期、状态、延迟天数均不落库。

## 原始值与操作

根长和苗长单位均为 mm，数据库使用 `Numeric(10,2)`。每项要么为非负数值（含 0），要么勾选无法测量且数值为空。空白表示尚未测定；正式测定行必须同时解决两项并记录实际测定时间。当天任意正常时间可测；早于计划自然日的记录拒绝，逾期日期可保存。

进行中实验可新增、修改、清除整条阶段测定；已完成实验只能修改已有记录，不能新增或清除；已终止的实验只读。测定创建、实际变化的纠错、清除以及位置标签更新均写审计。位置标签可自由填写或留空，样本所属培养皿、编号、发芽判定时间和来源巡检不可通过测定接口修改。

正式科研结果导出从“实验材料全集 × 计划幼苗槽位 × 本实验配置的 DAG”构造，再匹配真实幼苗及测定。长表每行是一个计划 sample-DAG 槽位，宽表每行是一个计划幼苗槽位；没有实际幼苗或测定的材料也保留完整设计位置。宽表按所选实验配置的 DAG 并集动态生成 RL/SL 列；长表只展开各实验自身的 DAG。数值 0、已有记录中明确无法测量的 `NA`、无数据空白严格区分。仅导出结构改变，不在数据库创建假幼苗或假测定。详细分析母体契约见[历史回填能力验证](10_历史回填能力验证.md)。本轮不计算总长、增长率、根苗比或统计汇总。

迁移 `b742b49a162e` 给测定表增加无法测量状态与备注，并将实际测定时间设为必填。已有半完成历史记录会阻止升级，提示人工核对；迁移不会猜填 0、NA 或时间。回退旧版时若存在 NA 或备注，也会阻止操作，避免静默丢失事实。

## 材料级每日工作流

工作台首先列实验材料，逾期优先、同级按实验内编号排序；SQL 聚合每份材料的今日、逾期、后续、今日完成和动态 DAG 数量。默认 25 份材料/页，可选 50/100。选择后仅加载该材料的样本 × DAG，自动选择第一条逾期或今日待测。保存后优先本材料下一条，今日任务完成后轻量提示并自动进入下一份有待处理任务的材料，Vue nextTick 后聚焦根长。

搜索使用普通输入，支持中文、英文、数字和连字符，001 精确匹配实验编号、001-1 匹配现场培养皿编号；搜索只刷新左侧结果，当前材料、填写值和焦点不会因搜索变化丢失。切换材料、任务、DAG、页签或离开页面时才检查未保存修改。修改已有测定只提交可编辑值，不携带幼苗或测定节点身份。

录入区旁显示同材料/同 DAG 的已有原始值，明确 0 与 NA，不混入尚未测定的阶段。本材料进度长表涵盖全部任务，根长和苗长独立显示，并列出计划日期、实际时间、状态与延迟、备注，仅已有测定显示修改入口。测定记录查询按材料（单选/多选/全部）、DAG、实际测定本地日期和名称筛选，服务端分页默认50，可选25/100；修改在独立对话框完成。

## 实验结束与保留履历

未置床、未巡检、无幼苗、无测定的草稿/已就绪实验可永久删除，编号确认和计划培养皿不属于实际执行事实。删除所有设计子项与实验在同一事务中完成，并保留删除审计。

完成实验的预检查要求没有未取消的待置床培养皿、没有仍在观察的已置床培养皿，且没有今日、逾期、后续或无法安排的幼苗测定。计划发芽观察天数仅作辅助提示，超过期限不能作为观察已完成的证据；当前没有独立的观察完成事实，因此已置床且未取消的培养皿仍计为观察中，不能仅因到期或测定全部录完而标记实验完成。本轮不增加观察完成闭环。若决定结束实验，使用现有终止入口，原因必填，记录结束时间并保留全部事实；之后所有执行修改拒绝。已有已完成实验状态保持不变，不能恢复进行中，但允许已有测定纠错。

Stage 3.1 migration `c6d91f28a405` 仅新增 `Experiment.termination_reason`（nullable Text）。回退至 `b742b49a162e` 时，如已有终止原因会安全拒绝，避免静默丢失履历；没有终止原因时可回退再升级。

## 工作台布局与查询保护

当前工作卡显示材料、当前DAG、今日剩余与当前培养皿/幼苗，完成后自动进入下一份待测材料。任务表紧凑且当前任务整行高亮；根长和苗长是主要输入，无法测量紧邻对应字段，时间、备注及位置标签弱化。参考区只显示同材料同DAG原始值，不计算统计。本材料测定进度与记录默认折叠，跨材料查询仍使用测定记录页。

输入与参考在浏览器宽度不足1700px时上下排列，宽屏允许双列，嵌套grid使用minmax(0,1fr)。记录查询统一省略空DAG、空日期等参数；0是有效DAG。搜索、材料、DAG、日期、分页只修改查询状态，保存修改才校验测定值。反馈展示当前过滤结果的总记录数及不同材料数，与当前页行数无关。中文名与学名分别换行显示。

## 本材料进度与全局记录排序

工作台底部为“本材料测定进度与记录”，默认折叠，显示已完成/总任务数量。展开后以当前材料全部样本×DAG任务显示已测、今日待测、已逾期、后续任务和无法安排；0、NA、未测（—）分别保留。按培养皿现场编号/重复、幼苗编号、DAG排序，不按录入时间排序。使用材料上下文的紧凑表格，省略重复实验编号和物种；保留根苗长、计划/实际时间、状态/延迟、备注，仅已有测定显示修改。窄屏由表格局部横向滚动兜底。

全局“测定记录”仍只显示已有正式测定，默认按实验编号、培养皿重复、幼苗编号、DAG、实际时间排序。发芽巡检表头为置床粒数、累计发芽、未发芽；没有巡检时累计发芽、发芽率和剩余数量为空，明确巡检 0 才显示零。v0.4.0 发布收口的迁移基线为 `c6d91f28a405`，当前开发分支 head 为实验类型迁移 `d2e7a46b910c`；科研导出槽位不增加数据库迁移。
