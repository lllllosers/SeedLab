# 幼苗测定业务规则（Stage 3，未发布）

## 计划与任务

每个实验配置任意非负 DAG 节点。幼苗样本的 `germinated_at` 是首次巡检判定发芽的时间；将它转为 `SEEDLAB_TIMEZONE` 指定的实验室日期，再加 DAG 自然日得到计划测定日期。时区默认 Asia/Shanghai。置床时间只用于培养皿和发芽巡检，不参与 DAG。缺少发芽判定时间的历史样本显示“无法安排”，不猜补日期。

任务由样本 × 测定节点动态派生，没有测定行时按计划日期分为已逾期、今日待测或后续任务；有完整测定行即已完成。逾期测定仍可录入。今日完成按实际测定时间的本地日期统计。计划日期、状态、延迟天数均不落库。

## 原始值与操作

根长和苗长单位均为 mm，数据库使用 `Numeric(10,2)`。每项要么为非负数值（含 0），要么勾选无法测量且数值为空。空白表示尚未测定；正式测定行必须同时解决两项并记录实际测定时间。当天任意正常时间可测；早于计划自然日的记录拒绝，逾期日期可保存。

进行中实验可新增、修改、清除整条阶段测定；已完成实验只能修改已有记录，不能新增或清除；已终止的实验只读。测定创建、实际变化的纠错、清除以及位置标签更新均写审计。位置标签可自由填写或留空，样本所属培养皿、编号、发芽判定时间和来源巡检不可通过测定接口修改。

联合导出长表只包含已有测定行，列出发芽判定、计划与实际测定时间及延迟天数。宽表按所选实验实际配置的 DAG 动态生成 RL/SL 列；数值 0、无法测量的 `NA`、未测定空白严格区分。Stage 3 不计算总长、增长率、根苗比或统计汇总。

## 材料级每日工作流（Stage 3.1）

工作台首先列实验材料，逾期优先、同级按实验内编号排序；SQL 聚合每份材料的今日、逾期、后续、今日完成和动态 DAG 数量。默认 25 份材料/页，可选 50/100。选择后仅加载该材料的样本 × DAG，自动选择第一条逾期或今日待测。保存后优先本材料下一条，今日任务完成后轻量提示并自动进入下一份有待处理任务的材料，Vue nextTick 后聚焦根长。

搜索使用普通输入，支持中文、英文、数字和连字符，001 精确匹配实验编号、001-1 匹配现场培养皿编号；搜索只刷新左侧结果，当前材料、填写值和焦点不会因搜索变化丢失。切换材料、任务、DAG、页签或离开页面时才检查未保存修改。修改已有测定只提交可编辑值，不携带幼苗或测定节点身份。

录入区旁显示同材料/同 DAG 的已有原始值，明确 0 与 NA，不混入尚未测定的阶段。完整历史改为长表，根长和苗长独立显示，并列出计划日期、实际时间、延迟天数、备注和修改入口。测定记录查询按材料（单选/多选/全部）、DAG、实际测定本地日期和名称筛选，服务端分页默认50，可选25/100；修改在独立对话框完成。

## 实验结束与保留履历

未置床、未巡检、无幼苗、无测定的草稿/已就绪实验可永久删除，编号确认和计划培养皿不属于实际执行事实。删除所有设计子项与实验在同一事务中完成，并保留删除审计。

完成实验必须没有未取消的待置床培养皿，实际置床培养皿均结束观察期，且没有今日、逾期、后续或无法安排的幼苗测定。条件不满足会明确列出剩余数量，不能强行标记完成。提前结束使用终止入口，原因必填，记录结束时间并保留全部事实；之后所有执行修改拒绝。已完成实验不能恢复进行中，但允许已有测定纠错。

Stage 3.1 migration `c6d91f28a405` 仅新增 `Experiment.termination_reason`（nullable Text）。回退至 `b742b49a162e` 时，如已有终止原因会安全拒绝，避免静默丢失履历；没有终止原因时可回退再升级。
