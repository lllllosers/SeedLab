# 200份历史材料的导入能力验证

本工具仅用于验证导入能力。数据库必须是系统临时目录中的一次性空业务测试库，不属于正式历史库，不进入备份机制。VERSION 仍为 0.4.1，迁移版本仍为 d2e7a46b910c。正式工作电脑部署和正式生产导入需以后单独确认。

## 源文件与已确认事实

读取“种子信息”“根-苗长统计表”和“试验设置”。不导入“发芽记录”、历史发芽率或任何干重。学名中的下划线仅转换为空格，不联网纠正学名。

## 使用方法

入口为 `scripts/maintenance/backfill_legacy_200_species.py`。只接受系统临时目录内已经迁移到当前版本的 `.db` 测试库，并要求该库已有唯一可用的负责人。自动测试夹具会在新建的临时目录准备迁移和测试负责人；工具本身不读取应用的默认数据库，不初始化或清空业务库。

```powershell
# 在仓库根目录执行；以下目标必须先准备为空业务临时测试库。
$testDatabase = Join-Path $env:TEMP 'seedlab-legacy-test\seedlab.db'
& .\.venv\Scripts\python.exe scripts\maintenance\backfill_legacy_200_species.py --source 'C:\Users\73971\Desktop\种子发芽试验结果统计(11).xlsx' --database $testDatabase --owner legacy-test-owner

# 仅当只读核验通过后，明确写入临时测试库。
& .\.venv\Scripts\python.exe scripts\maintenance\backfill_legacy_200_species.py --source 'C:\Users\73971\Desktop\种子发芽试验结果统计(11).xlsx' --database $testDatabase --owner legacy-test-owner --apply
```

`--data-root` 可替代 `--database`，仅表示系统临时目录中的测试目录，数据库文件为该目录下的 `seedlab.db`。含运行配置的目录和名为 SeedLabData 的目录被拒绝。目标必须关闭其他连接、完成 WAL 写入后再核验。

默认 dry-run 使用 SQLite immutable 只读连接，不改数据库，也不创建 WAL/SHM 文件；它核验源数据、迁移版本、负责人和空业务状态。apply 在一个事务中创建数据，数量核账、逐值核账及正式工作簿反向核账全部通过后才提交；任一失败均回滚。已导入的测试库再次执行时被拒绝，不覆盖、不追加重复历史数据。

缺失通过两条独立路径核验：总槽位减实际测定数，以及逐株逐DAG枚举空白槽位。两条路径在源文件和临时数据库中都必须得到40。

逐值比较以历史材料编号、幼苗序号、实际发芽时间、DAG、根长、苗长和实际测定时间为键与值，差异必须为0。真实0保留；双侧空白不创建测定记录；无发芽时间不创建样本。

正式工作簿由现有 `workbook_export.build` 生成，并重新读取导出的 XLSX 核验：

- `04_幼苗测定长表`：4955条实际测定，现场培养皿及完整幼苗编号正确。
- `05_幼苗测定宽表`：1665株真实幼苗；材料027地肤的01—10号幼苗均保留，六个根苗长值全部为空。所有40个缺失槽位仍为空，6个根长0和283个苗长0仍是数值0。
- 无内部培养皿长编号，无虚构巡检；200行发芽率汇总的累计发芽和发芽率均为空。
- 业务语义以巡检记录是否存在判断“未记录”。明确巡检0才显示累计0、发芽率0%；删除最后一次巡检后恢复未记录。

## 自动测试

原始文件不提交 Git。设置 `SEEDLAB_LEGACY_SOURCE` 后启用原文件集成测试；未设置时仅跳过依赖原文件的三项测试，其余发芽语义、导出和临时库保护测试正常执行。

```powershell
$env:SEEDLAB_LEGACY_SOURCE = 'C:\Users\73971\Desktop\种子发芽试验结果统计(11).xlsx'
$testRoot = Join-Path $env:TEMP ('SeedLab-check-' + [guid]::NewGuid().ToString('N'))
Set-Location backend
& ..\.venv\Scripts\python.exe -m pytest -q --basetemp=$testRoot
Set-Location ..\frontend
npm test
npm run build
```

测试数据库和可重新生成的导出均不是正式数据，不建立备份或长期留存。本轮不操作正式 SeedLabData，不合并 main，不修改 VERSION，不创建 tag 或 Release。
