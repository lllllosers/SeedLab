# SeedLab v0.4.1 — Production Trial Deployment

Stage 3.5 生产部署能力收口，供课题组试运行；不包含 Stage 4 统计分析。

- Windows portable：解压完整文件夹即可运行，无需日常安装 Python、Node 或 Git。
- SeedLab 运行控制中心：服务启停、重启、健康检查、托盘、日志和首位管理员初始化提示。
- Vue 与 API 单端口运行，提供本机、局域网和远程 HTTPS 入口；SakuraFrp 客户端独立管理。
- 程序和正式数据分离，提供正式 SQLite 在线手工备份、每日自动备份（默认保留 14 份）和数据库检查。只备份正式业务数据库，不建立源码、测试数据或构建产物备份体系。
- 五步首次部署向导、账号复用、单实例和可选 Windows 登录启动。
- 独立实例身份，不接管其他部署；新数据目录不串旧账号，保存重启后核对实际 LAN 运行配置。
