# 实验配置业务规则

## 默认方案和有效值

每个实验最多一条 `ExperimentProtocol`，保存默认每皿置床种子数、每材料重复数、观察周期、取样规则、取样数与范围、发芽判定标准和备注。当前仅支持 `first_germinated`（按发芽顺序取前 N 株）；判定标准是实验者填写的文字，不内置固定长度阈值。

`ExperimentMaterial` 表示参与实验的一个 SeedLot。同一实验不能重复加入同一批次，停用批次不能新加入。`display_order` 保留人工排序。材料的 `seeds_per_dish_override`、`replicate_count_override`、`sample_count_override` 为 `NULL` 时分别继承协议默认值。服务层给出 `effective_seeds_per_dish`、`effective_replicate_count`、`effective_sample_count`；前端直接显示这三个有效值。数值均需大于 0。已产生培养皿执行数据的材料不能移除。

取样范围 `per_dish` 表示每个培养皿取 N 株，此时有效 N 不得超过有效每皿种子数。`per_material` 表示每个实验材料合计取 N 株，此时有效 N 不得超过有效每皿种子数乘有效重复数。更新默认方案或任一材料覆盖时重新校验所有受影响材料。

## DAG 与两套时间基准

实验的 DAG（Days After Germination）时间点为非负整数，实验内唯一，保存与读取时升序排列。创建向导预填 3、7、14 天只是可修改的界面建议；数据库和服务不以这些数字作为固定规则。未来测定任务以单株 `SeedlingSample.germinated_at + day_after_germination` 计算。培养皿的 `sown_at` 是置床时间，用于未来发芽巡检的置床后天数派生，与 DAG 分开。

## 动态工作量估算

设每个材料的有效重复数为 `R`、有效每皿种子数为 `S`、有效取样数为 `N`，DAG 节点数为 `D`：

- 材料数：所选材料条数。
- 预计培养皿数：`Σ R`。
- 预计置床种子数：`Σ (R × S)`。
- 预计幼苗取样数：每皿取样为 `Σ (R × N)`；每材料取样为 `Σ N`。
- 预计根苗长测定记录数：预计样本数 `× D`。
- 若填写计划开始日期，预计最晚完成日期为该日期 `+ 观察周期天数 + 最大 DAG`。这是设计估算，不是实际结束时间。

估算按当前配置即时计算，不冗余保存。Stage 1 只保存实验设计，不生成培养皿、幼苗样本、巡检记录或测定任务。`draft` 和 `ready` 可以修改设计；`active`、`completed`、`cancelled` 禁止结构性配置变化。
