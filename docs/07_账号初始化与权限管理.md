# 账号初始化与权限管理

## 首次初始化

数据库没有任何 `User` 时，`GET /api/setup/status` 只返回 `{ "initialized": false }`，不返回初始化码。服务启动时使用加密安全随机数生成一次性 Bootstrap Token，存于服务器本机 `data/bootstrap.token`（可通过 `SEEDLAB_BOOTSTRAP_TOKEN_PATH` 调整），并打印到本机终端。该文件位于 Git 忽略目录，不写入网页源码或数据库业务字段。生产模式也只能从服务器本机取得初始化码。

打开 `/setup`，填写初始化码、管理员用户名、显示姓名、密码及确认密码。后端使用 SQLite 写事务锁串行化并发请求；只有数据库仍无用户且初始化码正确时，才创建首个 `is_admin=true`、`must_change_password=false` 的管理员。密码仅存 Argon2 hash，创建和审计、正常 Session 一起提交。提交后立即删除初始化码文件，并跳转工作台。数据库已有任意用户时，Bootstrap 接口永久拒绝再次初始化；即使残留码文件，也不会再次生效。

服务器本机保留 `cd backend; ..\.venv\Scripts\python.exe -m app.cli create-admin admin --name "管理员"` 作为应急、维护和本地恢复入口。CLI 不依赖 Bootstrap Token；用户名称唯一，密码规则与网页一致，操作结果在终端明确显示。没有预设账号或密码，也没有公开注册或 `/register`。

## 密码与成员

密码长度统一为 **8 至 128 位**，允许密码短语，不强制大写、小写、数字和符号组合。管理员可在用户管理页创建成员、修改显示姓名、调整管理员角色、启停账号并重置其他成员的密码。新建成员的密码是临时密码，`must_change_password=true`；管理员重置密码后同样置为 `true`。首个 Bootstrap 管理员和迁移前已有用户默认 `false`。不提供直接删除用户的接口。

临时密码用户登录后只能访问 `/auth/me`、`/auth/change-password` 和 `/auth/logout`；前端进入 `/change-password`，后端对业务 API 同样拒绝访问。改密须验证当前密码，新密码不得与旧密码相同。改密成功清除该用户**全部 SessionToken**，包括当前设备，清除强制改密标记，并要求重新登录。管理员重置密码和停用账号也立即清除目标用户的全部 SessionToken；停用账号不能重新登录，启用后可以使用仍有效的密码登录。

管理员不能停用自己、取消自己的管理员权限或移除最后一个启用的管理员。操作审计仅记录安全的姓名、角色、状态和改密事件，不记录明文密码、password_hash 或 Bootstrap Token。

## v0.6.0 本机管理员账户恢复

控制中心“设置与关于”提供已有管理员选择、新密码及确认密码。使用现有 8—128 位及 Argon2 规则，只恢复所选启用管理员的密码并清除其全部会话；将 must_change_password 置 false，因为这是管理员在本机选择的新密码。其他账号、角色、实验数据、审计表与 schema 保持，既有 Web 成员临时密码流程不变。

若本控制中心拥有运行中的服务，用户确认后正常停止，维护完成后重启；维护期间禁止再次启动。其他入口运行时须先从原入口停止。数据库占用、结构不匹配、账号非管理员或已停用时拒绝；不创建管理员，不清除停用状态。现模型无登录失败锁定字段，不新增锁定模型。密码输入清空，日志只记录维护结果，绝不记录明文。

本地恢复要求拥有该电脑和 Data Root 的访问权，不新增 Web 密码恢复接口，不执行初始化或历史导入。完整运维流程见[生产运维](10_生产部署与控制中心设计.md#管理员恢复与结构版本)。
