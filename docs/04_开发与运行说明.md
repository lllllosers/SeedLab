# 开发与运行说明

## 前提

Windows、Python 3.12+、Node.js 20+、npm、Git。项目目录为 `E:\gitProject\SeedLab`。首次安装：

```powershell
cd E:\gitProject\SeedLab
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e './backend[test]'
cd frontend
npm install
cd ..
Copy-Item .env.example .env
```

可在 `.env` 中设置 `SEEDLAB_ENV`（`development` / `production`）、`SEEDLAB_DATABASE_URL`、`SEEDLAB_SESSION_HOURS`、`SEEDLAB_COOKIE_SECURE`。`.env`、SQLite、上传、日志、备份、虚拟环境和构建产物都不会进入 Git。

## 数据库与管理员

```powershell
cd backend
..\.venv\Scripts\python.exe -m alembic upgrade head
..\.venv\Scripts\python.exe -m alembic current
..\.venv\Scripts\python.exe -m app.cli create-admin admin --name "管理员"
cd ..
```

CLI 交互输入至少 10 位密码，不存在预设管理员密码。执行迁移前不应启动 API；应用不调用 `create_all`。

当前 Alembic head 为 `9456099da4fd`。升级采用 `alembic upgrade head`。若需验证本次语义修复迁移的可回退性，可在测试数据库上执行 `alembic downgrade 3179cf93a5f4`，再执行 `alembic upgrade head`；不要在有真实数据的数据库上随意回退，因为回退会移除 `germinated_at` 列及其中的值。

## 启动与检查

在仓库根目录运行 `run_dev.bat`。脚本检查依赖、执行迁移并在同一个终端启动 API 和 Vite；Ctrl+C 停止。访问 <http://localhost:5173>，API 健康检查 <http://localhost:8000/api/health>，开发文档 <http://localhost:8000/docs>。

运行 `run_tests.bat`（pytest）和 `cd frontend; npm run build`（TypeScript 检查 + Vite 构建）。

## 局域网与安全

开发脚本监听所有网卡，供局域网浏览器访问。生产环境应在可信代理后通过 HTTPS 提供同源页面和 API，设置 `SEEDLAB_ENV=production` 与 `SEEDLAB_COOKIE_SECURE=true`，并限制访问来源。开发脚本不等于生产部署。若使用公网穿透，应先配置 HTTPS 与访问控制，不要直接暴露开发服务器。SQLite 数据库及其 WAL/SHM 文件需要一致性备份；不要在运行中直接复制单个 `.db` 文件当作可靠备份。

## API 概览

| 范围 | 路径 |
| --- | --- |
| 状态 | `GET /api/health` |
| 认证 | `POST /api/auth/login`、`GET /api/auth/me`、`POST /api/auth/logout` |
| 物种 | `GET/POST /api/taxa`、`GET/PATCH/DELETE /api/taxa/{id}` |
| 种子批次 | `GET/POST /api/seed-lots`、`GET/PATCH/DELETE /api/seed-lots/{id}` |
| 实验 | `GET/POST /api/experiments`、`GET/PATCH/DELETE /api/experiments/{id}` |
| 工作台 | `GET /api/dashboard` |
| 系统 | `GET /api/audit-logs`、`GET/POST /api/users`（仅管理员） |
| 数据交换 | `POST /api/import/taxa`、`GET /api/export/taxa.csv` |

登录以外的业务 API 需要会话。POST/PATCH/DELETE 必须附带登录或 `/auth/me` 返回的 `X-CSRF-Token`。物种导入使用首行含 `scientific_name` 的 `.xlsx`，可选 `common_name`、`family`。导入最多 500 行、2 MB，学名重复整批拒绝。

幼苗根苗长时间点采用 DAG（Days After Germination）：`MeasurementTimepoint.day_after_germination` 为实验内唯一的非负天数；未来计划按单株 `SeedlingSample.germinated_at` 计算。`GerminationDish.sown_at` 仍表示培养皿置床时间，若巡检需要置床后天数，应由它派生。
