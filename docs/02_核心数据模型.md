# 核心数据模型

首次迁移：`3179cf93a5f4_initial_schema.py`；DAG 修复：`9456099da4fd_align_germination_based_dag.py`；当前 head：`d50447b51d78_stage1_experiment_configuration.py`。13 个约定业务实体，加一张 `sessions` 会话表。

| 实体 | 核心字段 | 关系或约束 |
| --- | --- | --- |
| User | username、password_hash、is_admin、is_active | 用户名唯一；密码 Argon2 |
| Taxon | code、scientific_name、common_name、family、is_active | 编号与学名唯一；一对多 SeedLot |
| SeedLot | code、taxon_id、source、quantity | Taxon 外键；数量可缺失或 ≥ 0 |
| Experiment | code、name、status、planned_start_date、owner_id、started_at、ended_at | 草稿/就绪/进行中/完成/取消 |
| ExperimentProtocol | experiment_id、summary、seeds_per_dish、replicate_count、observation_period_days、sampling_rule、sample_count、sample_scope、germination_criterion | 每实验至多一条；配置数值 > 0；旧数据字段可空 |
| ExperimentMaterial | experiment_id、seed_lot_id、label、display_order、seeds_per_dish_override、replicate_count_override、sample_count_override | 实验和种子批次组合唯一；覆盖值可空且非空时 > 0 |
| MeasurementTimepoint | experiment_id、day_after_germination、label | DAG 为非负整数；同一实验内唯一 |
| GerminationDish | material_id、label、seed_count、sown_at | 材料内标签唯一；粒数 > 0 |
| GerminationObservation | dish_id、observed_at、new_germinated_count、notes | 培养皿和时间唯一；新增数 ≥ 0 |
| SeedlingSample | dish_id、sample_number、germinated_at | 培养皿内样本号唯一；实际发芽时间当前可缺失 |
| SeedlingMeasurement | sample_id、timepoint_id、root_length_mm、shoot_length_mm | 样本和时间点唯一；长度可为 0 或 NULL |
| AuditLog | user_id、action、entity_type、entity_id、before、after | 重要数据变更留痕 |
| ImportJob | user_id、filename、status、行数 | 物种导入结果 |
| SessionToken | user_id、token_hash、csrf_token、expires_at | HttpOnly Cookie 对应的服务器会话 |

主链为 `Taxon → SeedLot → ExperimentMaterial → GerminationDish → GerminationObservation`；另一支为 `GerminationDish → SeedlingSample → SeedlingMeasurement`。`Experiment` 拥有 `ExperimentProtocol`、`MeasurementTimepoint`、`ExperimentMaterial`。

**原始事实原则：** 巡检记录仅存本次新增发芽数与观测时间，不存累计数、发芽率或置床后天数。数值 0 表示实际观测或测量得到 0；无记录或 `NULL` 表示缺失。根苗长按“样本 + 时间点”长表保存，DAG 节点动态配置，没有 `root_3d` 一类列。Stage 1 开放实验设计，不开放巡检和测量 API。

**两套时间基准：** 幼苗根苗长计划采用 DAG（Days After Germination），即单株幼苗实际发芽后的第 N 天；未来以 `germinated_at + day_after_germination` 计算该株测定任务。`germinated_at` 记录判定发芽的实际日期时间，当前允许 `NULL` 以兼容尚未开放的样本业务及后续历史迁移。培养皿的 `sown_at` 保留为置床时间；未来巡检需要的置床后天数可由它派生，与 DAG 不混用。`source_observation_id` 暂不加入，待样本选择流程明确后再保证它与样本所属培养皿一致。

`ExperimentProtocol` 是实验默认方案；材料三个 `override` 字段为 `NULL` 时继承默认参数。有效值与工作量在服务层动态计算，详情见 [实验配置业务规则](05_实验配置业务规则.md)。Stage 1 不生成 `GerminationDish`。

SQLite 开启外键、30 秒 busy timeout 和 WAL。所有结构变更经 Alembic。删除已被下游引用的记录由外键拒绝；工作台、编辑页面主要使用停用状态保留履历。
