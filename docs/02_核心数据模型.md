本文记录 v0.5.1 的当前物理 schema，模型权威来源为 `backend/app/models/entities.py` 和完整 Alembic 迁移链。AF-0 不新增表、字段或 migration；目标职责划分见[总体设计](01_系统总体设计.md)，逻辑归属不能被理解为已实现的模块拆分。

| 实体 | 核心字段 | 关系或约束 |
| --- | --- | --- |
| User | username、password_hash、is_admin、is_active、must_change_password | 用户名唯一；密码 Argon2；历史用户默认不强制改密，新建成员默认强制 |
| Taxon | code、scientific_name、common_name、family、genus、life_form、is_active | 编号与学名唯一；一对多 SeedLot；属与生活型可空 |
| SeedLot | code、taxon_id、source_code、source、collected_at、quantity | Taxon 外键；原始材料编号、采集/获得日期可空；数量可缺失或 ≥ 0 |
| Experiment | code、experiment_type、name、status、planned_start_date、numbering_locked_at、owner_id、started_at、ended_at、termination_reason | 类型非空且当前仅 GER；创建后不可改类型或编号；草稿/就绪/进行中/完成/终止；编号确认时间和终止原因可空 |
| ExperimentProtocol | experiment_id、summary、seeds_per_dish、replicate_count、observation_period_days、sampling_rule、sample_count、sample_scope、germination_criterion | 每实验至多一条；计划发芽观察天数可空、有值时 > 0，仅作预计日期和超期提醒；核心配置必填；旧数据字段可空 |
| ExperimentMaterial | experiment_id、seed_lot_id、experiment_number、label、display_order、seeds_per_dish_override、replicate_count_override、sample_count_override | 实验和种子批次组合唯一；本次实验编号可空、正数且实验内唯一；覆盖值可空且非空时 > 0 |
| MeasurementTimepoint | experiment_id、day_after_germination、label | DAG 为非负整数；同一实验内唯一 |
| GerminationDish | material_id、code、replicate_no、label、seed_count、sown_at、cancelled_at、cancel_reason | code 全局唯一；材料内重复号及标签唯一；重复号与粒数 > 0；实际置床与取消不可同时存在 |
| GerminationObservation | dish_id、observed_at、new_germinated_count、notes | 培养皿和时间唯一；新增数 ≥ 0 |
| SeedlingSample | dish_id、sample_number、germinated_at、source_observation_id、position_label | 培养皿内样本号唯一；来源巡检可追踪；历史行允许缺失 |
| SeedlingMeasurement | sample_id、timepoint_id、root_length_mm、shoot_length_mm、root_unavailable、shoot_unavailable、measured_at、notes | 样本和时间点唯一；每项必须是非负数值（含 0）或明确无法测量；测定时间必填 |
| AuditLog | user_id、action、entity_type、entity_id、before、after | 重要数据变更留痕 |
| ImportJob | user_id、filename、file_hash、status、行数 | 导入结果；成功一体导入文件的 SHA-256 唯一 |
| SessionToken | user_id、token_hash、csrf_token、expires_at | HttpOnly Cookie 对应的服务器会话 |

主链为 `Taxon → SeedLot → ExperimentMaterial → GerminationDish → GerminationObservation`；另一支为 `GerminationDish → SeedlingSample → SeedlingMeasurement`。`Experiment` 拥有 `ExperimentProtocol`、`MeasurementTimepoint`、`ExperimentMaterial`。

**原始事实原则：** 巡检记录仅存本次新增发芽数与完整观测时间，不存累计数、发芽率或置床后天数。数值 0 表示已巡检且本次没有新增；无记录表示没有巡检。根苗长按“样本 + 时间点”长表保存，DAG 节点动态配置，没有 `root_3d` 一类列。没有测定行表示尚未测定；有行表示根长和苗长均已明确解决。测定任务、状态、延迟天数由事实实时派生，不建任务表。

**两套时间基准：** 幼苗根苗长计划采用 DAG（Days After Germination），即单株幼苗被判定发芽后的第 N 天；先把 `germinated_at` 转为实验室本地自然日，再加 `day_after_germination` 天得到计划日期，不要求同一具体时刻。`germinated_at` 等于来源巡检的 `observed_at`，表示首次在巡检中判定该幼苗发芽的时间，不表示生理发芽瞬间。历史样本可为 `NULL`，此时任务无法安排；新选样本记录 `source_observation_id`。培养皿的 `sown_at` 是实际置床时间；巡检需要的置床后天数可由它派生，与 DAG 不混用。

`ExperimentProtocol` 是实验默认方案；材料三个 `override` 字段为 `NULL` 时继承默认参数。有效值与工作量在服务层动态计算，详情见 [实验配置业务规则](05_实验配置业务规则.md)。当前工作流在确认置床编号时生成尚未置床的计划培养皿；第一次真实置床时实验进入 `active`，`started_at` 取最早实际置床时间。累计、发芽率和观察进度不冗余存库。

**稳定编号：** 物种 `SP-NNNN` 全局流水、批次 `LOT-YYYY-NNN` 按年流水，是永久身份；批次可另存来自原表的 `source_code`。新实验编号 `TYPE-YYYYMM-NNN` 按独立的 `experiment_type` 和年月分配，当前 `GER` 显示为“种子萌发试验”。年月在创建时优先取 `planned_start_date`，否则取实验室时区（默认 Asia/Shanghai）的当前年月，创建后永久不改。旧 `EXP-YYYY-NNN` 编号保持原样，不占 GER 流水。

`ExperimentMaterial.experiment_number` 在各实验内从 001 开始，确认后锁定。培养皿现场编号由它与重复号派生（单重复 001，多重复 001-1）；幼苗完整编号为 001-01 或 001-1-01，由集中助手生成。`GerminationDish.code` 仍是内部唯一技术标识，不用于普通页面、业务搜索或正式 Excel。UUID 同样不展示。名称、日期和列表排序变化不触发重编号。联合导出的汇总编号只在工作簿内按所选材料重新排序生成，绝不回写。

v0.5.0新增迁移 `d2e7a46b910c`，接续 v0.4.1 的 `c6d91f28a405`，只增加非空、受 GER 检查约束的实验类型并回填既有实验，保留全部编号和关联数据。

历史200份材料已正式导入目标电脑并核账；其根苗长实际测定时间严格为 `measured_at = germinated_at + DAG`，是实际发生时间，不是推定或计划时间，没有提前或推迟。历史实验为已完成，未知结束时间保持为空，当前任务为0；没有新增干重字段或统计分析。

数据库只保存真实幼苗和测定，计划槽位不是 ORM 实体或表。设计全集、历史计数及导出语义以[科研数据与导出回归契约](14_历史数据与导出回归契约.md)为唯一权威来源。

## 逻辑归属与当前物理关系

| 逻辑范围 | 当前实体 / 事实 | 尚未完成的边界 |
| --- | --- | --- |
| Platform | User、SessionToken | 公共能力与业务服务依赖整理 |
| Catalog | Taxon、SeedLot、ImportJob | 保持跨实验共享材料身份 |
| Experiment Core / GER | Experiment、ExperimentProtocol、ExperimentMaterial | 当前通用配置直接使用 GER 默认方案，逻辑职责待后续拆分 |
| GER | GerminationDish、GerminationObservation、first-N 来源事实 | 当前通过 dish 关联 SeedlingSample，不能在拆分时丢失来源或稳定身份 |
| Measurement | MeasurementTimepoint、SeedlingSample、SeedlingMeasurement | 当前节点归属于 Experiment、样本依赖 GER 培养皿；目标归属不改变当前外键 |
| Audit | AuditLog | 继续随关键写入事务保存前后快照 |
| Operations / Analysis | 当前没有新增业务表 | 目标架构不能提前写成已实现 schema |

**Logical target != current physical schema。** 此表仅说明后续边界的审计入口；AF-0 保留全部当前实体、外键、唯一性和长度约束。

SQLite 开启外键、30 秒 busy timeout 和 WAL。所有结构变更经 Alembic。删除已被下游引用的记录由外键拒绝；工作台、编辑页面主要使用停用状态保留履历。
