# 开发路线图

## Stage 0 — Foundation（当前，0.1.0-dev）

- 13 个核心实体、UUID 与首版 Alembic 迁移。
- 登录、管理员初始化、简单权限和审计基础。
- 工作台、物种信息库、种子批次、实验列表与基础详情。
- 物种 Excel 导入、CSV 导出，自动化测试与 Windows 开发入口。
- 收口幼苗测定时间语义：DAG 节点按发芽后天数定义，样本保留实际发芽时间。
- 验收后准备 `v0.1.0`，沿 `main` 与短期 `feat/*`、`fix/*` 工作。

## 推荐 Stage 1 — 实验配置

围绕现有 Experiment、ExperimentProtocol、ExperimentMaterial 和 MeasurementTimepoint 开发实验设计页面与 API：选择种子批次、记录实验方案、配置动态 DAG（Days After Germination）节点。后续测定任务以单株 `germinated_at` 为基准计算；本轮只修正 Stage 0 模型，不进入实验配置或任务生成。

## 后续增量

- Stage 2：培养皿与发芽巡检，明确 0 和缺失、累计计算及数据校验。
- Stage 3：幼苗样本与根苗长长表录入。
- Stage 4：派生指标、图表、导出与历史履历。

GBIF/WFO/COL、WinRHIZO、仪器连接、标签/二维码、复杂 Treatment、邮件、审核工作流与生产便携部署均另行评估，不提前建设空模块。
