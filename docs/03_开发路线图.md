# 开发路线图

## Stage 0 — Foundation（已完成）

- 13 个核心实体、UUID 与首版 Alembic 迁移。
- 登录、管理员初始化、简单权限和审计基础。
- 工作台、物种信息库、种子批次、实验列表与基础详情。
- 物种 Excel 导入、CSV 导出，自动化测试与 Windows 开发入口。
- 收口幼苗测定时间语义：DAG 节点按发芽后天数定义，样本保留实际发芽时间。
- 已完成基础数据与 DAG 语义修复，作为 Stage 1 开发基线。

## Stage 1 — 实验配置（当前，0.1.0-dev）

围绕 Experiment、ExperimentProtocol、ExperimentMaterial 和 MeasurementTimepoint 实现七步实验创建向导、默认参数与材料覆盖、动态 DAG、取样容量校验、工作量估算及可编辑详情。后续测定任务以单株 `germinated_at` 为基准计算。本阶段不生成培养皿、样本或任务。

## 后续增量

- Stage 2：在已确认的实验配置基础上生成培养皿并开展发芽巡检，明确 0 和缺失、累计计算及数据校验。
- Stage 3：幼苗样本与根苗长长表录入。
- Stage 4：派生指标、图表、导出与历史履历。

GBIF/WFO/COL、WinRHIZO、仪器连接、标签/二维码、复杂 Treatment、邮件、审核工作流与生产便携部署均另行评估，不提前建设空模块。
