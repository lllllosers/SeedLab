# 开发路线图

当前稳定生产版本为 **v0.5.1**。主程序投产、历史 200 材料导入及 Project Hygiene 已完成；开发主线现在进入 **Architecture Foundation**。本文件是仓库内唯一精简路线图，具体实施范围以各阶段任务定义为准，不在仓库复制完整总控计划。

~~~text
v0.5.1 stable production
          ↓
Architecture Foundation
AF-0 → AF-1 → AF-2 → AF-3 → AF-4 → AF-5 → AF-6
          ↓
future functional development
~~~

## 当前阶段边界

AF-0 仅阅读审计、补最小 Characterization / Regression Tests、整理现行权威文档并运行质量门。保持 VERSION 0.5.1 与 Alembic head d2e7a46b910c；不新增 migration，不改变业务、用户流程、科研语义或 workbook 格式，不修改正式产物或 v0.5.1 tag。独立 AF-0 分支完成测试和文档提交后停止，不合并 main，不开始 AF-1。

## 已完成历史与后续功能

Stage 0—3.5 已交付平台、实验配置、GER 执行、账号初始化、幼苗测定及生产部署；v0.5.0—v0.5.1 收口稳定实验身份、计划长宽表和终态待办。发布历史由[release 文档](README.md#发布历史)、[CHANGELOG](../CHANGELOG.md)、Git tag 和 Release 承担，不保留阶段开发流水账。

Architecture Foundation 验收后再进入功能开发。干重、观察结束闭环、统计分析、RGR/AGR、异常值、ANOVA、Duncan、图表、数据库恢复与升级器仍未实现；本阶段不追加它们。外部分类名录、仪器连接、标签/二维码、复杂 Treatment 和审核工作流届时按真实需求评估。
