## 当前阶段边界

AF-4 已人工验收，以 fast-forward 合入并同步 main `21b450c7594446ffb8a6ea4c36a87e6c97e19170`，临时 AF-4 分支已清理。AF-5 从该提交建立 `architecture/af5-frontend-boundaries`；前端通用实验负责身份契约、列表、导航与类型分发，GER 拥有创建、配置和执行流程，Measurement 拥有录入、工作台与履历。静态 UI registry 只映射当前 GER bundle，类型事实和生命周期仍由后端决定。保持 URL、query、界面文案、CSS、流程、API、身份、first-N、germinated_at、0/NA/blank、VERSION 0.5.1 和 Alembic head d2e7a46b910c；不修改后端生产代码、schema、迁移、依赖、IDE 或正式分发产物。

数据库恢复通过独立显式操作落实，Legacy Importer 不参与灾难恢复。Current/Previous/Staging 程序槽位管理需调整 portable 布局和 Control Center 生命周期，延期为 AF-1.x deployment enhancement；不在 AF-1 重写控制中心、开发在线检查/下载更新或完整 GFS 界面。升级、恢复及保留边界见[生产运维](10_生产部署与控制中心设计.md)。AF-5 完成后提交独立分支并停止，等待人工验收；不合并 main，不进入 AF-6。

## 已完成历史与后续功能

Stage 0—3.5 已交付平台、实验配置、GER 执行、账号初始化、幼苗测定及生产部署；v0.5.0—v0.5.1 收口稳定实验身份、计划长宽表和终态待办。发布历史由[release 文档](README.md#发布历史)、[CHANGELOG](../CHANGELOG.md)、Git tag 和 Release 承担，不保留阶段开发流水账。

Architecture Foundation 验收后再进入功能开发。干重、观察结束闭环、统计分析、RGR/AGR、异常值、ANOVA、Duncan、图表和完整应用发布升级器仍未实现；本阶段不追加它们。外部分类名录、仪器连接、标签/二维码、复杂 Treatment 和审核工作流届时按真实需求评估。
