## 当前阶段边界

AF-1 从已同步的 main 基线 `6bd209bed672a9914b5f02d6f75882bb1980e904` 开始，分支为 `architecture/af1-upgrade-recovery`。保持 VERSION 0.5.1 与 Alembic head d2e7a46b910c；不新增 migration，不改变业务、科研语义或 workbook 格式，不修改正式产物或 v0.5.1 tag。只在数据库不兼容或升级失败时提供更明确的启动提示。

数据库恢复通过独立显式操作落实，Legacy Importer 不参与灾难恢复。Current/Previous/Staging 程序槽位管理需调整 portable 布局和 Control Center 生命周期，延期为 AF-1.x deployment enhancement；不在 AF-1 重写控制中心、开发在线检查/下载更新或完整 GFS 界面。升级、恢复及保留边界见[生产运维](10_生产部署与控制中心设计.md)。AF-1 完成后提交独立分支并停止，不合并或推送 main，不进入 AF-2。

## 已完成历史与后续功能

Stage 0—3.5 已交付平台、实验配置、GER 执行、账号初始化、幼苗测定及生产部署；v0.5.0—v0.5.1 收口稳定实验身份、计划长宽表和终态待办。发布历史由[release 文档](README.md#发布历史)、[CHANGELOG](../CHANGELOG.md)、Git tag 和 Release 承担，不保留阶段开发流水账。

Architecture Foundation 验收后再进入功能开发。干重、观察结束闭环、统计分析、RGR/AGR、异常值、ANOVA、Duncan、图表和完整应用发布升级器仍未实现；本阶段不追加它们。外部分类名录、仪器连接、标签/二维码、复杂 Treatment 和审核工作流届时按真实需求评估。
