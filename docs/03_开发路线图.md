## 当前阶段边界

AF-1 已人工验收，以 fast-forward 合入并同步 main `67dafb455e9346e20bea381b1fc209bbeac7f0c3`，临时 AF-1 分支已清理。AF-2 从该提交建立 `architecture/af2-contracts-dependencies`；只调整增长域 DTO 和错误边界，保持 HTTP path/method、request/response、status/detail/headers、Auth/CSRF 与 OpenAPI。保持 VERSION 0.5.1 和 Alembic head d2e7a46b910c；不修改 schema/migration、业务、科研语义、workbook、前端、正式产物、tag 或 IDE 配置。

数据库恢复通过独立显式操作落实，Legacy Importer 不参与灾难恢复。Current/Previous/Staging 程序槽位管理需调整 portable 布局和 Control Center 生命周期，延期为 AF-1.x deployment enhancement；不在 AF-1 重写控制中心、开发在线检查/下载更新或完整 GFS 界面。升级、恢复及保留边界见[生产运维](10_生产部署与控制中心设计.md)。AF-2 完成后提交独立分支并停止，等待人工验收；不合并 main，不进入 AF-3。

Stage 0—3.5 已交付平台、实验配置、GER 执行、账号初始化、幼苗测定及生产部署；v0.5.0—v0.5.1 收口稳定实验身份、计划长宽表和终态待办。发布历史由[release 文档](README.md#发布历史)、[CHANGELOG](../CHANGELOG.md)、Git tag 和 Release 承担，不保留阶段开发流水账。
